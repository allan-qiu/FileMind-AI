# Reporting authentication and access-control issues

Do not disclose passwords, API keys, private files or usable share links in
public issues. If this repository's owner enables GitHub private vulnerability
reporting, use that channel. Otherwise open an issue requesting a private contact
method without exploit details or credentials.

This document concerns software authentication, permissions and development
practices. It does not describe a file scanning or quarantine feature.

This is a pre-release; production readiness and supported environments are
documented in README and `docs/PUBLIC_RELEASE.md`.
