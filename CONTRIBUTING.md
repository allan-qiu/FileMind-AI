# Contributing

Use Python 3.12 and a Node version supported by `web/package.json`. Install the
locked dependencies and run the commands in README before opening a pull request.

Preserve Windows, API, `/app/`, `/admin/`, public sharing and migration checks.
Use synthetic files and isolated databases. Tests and CI must not call paid AI,
write a real cloud account, modify a production service or require credentials.

Report the concrete behavior changed, relevant tests and remaining limitations.
Do not attach runtime databases, keys, passwords, access tokens or private files.
FileMind does not implement antivirus, malware detection or quarantine features.
